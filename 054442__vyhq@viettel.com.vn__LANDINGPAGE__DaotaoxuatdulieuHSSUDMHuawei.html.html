Trích xuất trên Node HSS

  • ●
    Xuất MML: Thực thi lệnh EXP trên giao diện LMT để lấy cấu hình.
  • ●
    Xuất thuê bao: Thiết lập điều kiện lọc theo IMSI/MSISDN trên SingleSDB DTL Web.

Trích xuất trên Node UDM

  • ●
    Xuất MML: Thực thi lệnh qua giao diện CSP Web hiện đại.
  • ●
    Xuất qua DMS Web: Quy trình tạo Export Task, theo dõi tiến độ và download file kết quả.
